# Sécurité de votre compte

Votre argent est protégé par votre code secret. Voici comment le garder en sécurité, et quoi faire en cas de problème.

## Code secret et empreinte

Votre code secret à 6 chiffres vous est demandé pour chaque paiement. Vous pouvez aussi activer l'empreinte digitale ou la reconnaissance faciale dans Profil, puis Sécurité.

Après 5 codes faux de suite, votre compte est bloqué pendant 24 heures. Si vous avez oublié votre code, touchez Code oublié sur l'écran de connexion : vous confirmez avec un code reçu par SMS et votre date de naissance, et un compte de niveau 2 doit aussi prendre un selfie.

## Ne donnez jamais vos codes

Acme Pay ne vous demandera jamais votre code secret ni un code reçu par SMS : ni par téléphone, ni par SMS, ni sur WhatsApp ou les réseaux sociaux. Nos SMS viennent toujours de l'expéditeur ACMEPAY, et notre seul site est acme-pay.example.

Quelqu'un qui connaît votre code secret peut vider votre portefeuille. Si vous l'avez donné, changez-le tout de suite dans Profil, puis Sécurité.

## Téléphone perdu ou volé

Bloquez votre compte au plus vite :

- en appelant le service client ;
- ou sur acme-pay.example/bloquer, avec votre numéro et votre date de naissance.

Demandez ensuite à votre opérateur une nouvelle carte SIM avec le même numéro. Installez Acme Pay sur votre nouveau téléphone et connectez-vous : votre solde et votre historique sont conservés.

## Une opération que vous ne reconnaissez pas

Signalez-la dans les 30 jours, depuis Historique ou auprès du service client. Nous bloquons votre compte le temps de l'enquête, qui dure au plus 10 jours ouvrables.

Si l'opération est frauduleuse et que vous n'avez pas commis de négligence, nous vous remboursons. Si vous avez donné votre code secret ou un code reçu par SMS, nous ne remboursons pas.

## Arnaques fréquentes

- **Faux agents :** quelqu'un se présente comme employé d'Acme Pay et vous demande un code. Raccrochez.
- **Faux remboursements :** on vous demande d'envoyer de l'argent pour recevoir un remboursement. Acme Pay ne demande jamais d'argent pour rembourser.
- **Faux vendeurs :** on vous demande de payer par envoi Acme Pay un article qui n'arrive jamais. Un envoi ne peut pas être annulé : ne payez que des personnes que vous connaissez.
