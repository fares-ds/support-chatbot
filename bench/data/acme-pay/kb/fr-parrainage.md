# Parrainage

Invitez vos proches sur Acme Pay : quand ils remplissent les conditions, vous recevez chacun 200 DA.

## Comment ça marche

1. Dans Profil, puis Parrainer, partagez votre code de parrainage.
2. Votre filleul saisit ce code quand il crée son compte. Un code ne peut plus être ajouté après la création du compte.
3. Dans les 30 jours, votre filleul passe au niveau 2 et fait une première opération d'au moins 1 000 DA.

Vous recevez alors chacun 200 DA, sous 48 heures.

## Conditions

- Vous pouvez parrainer jusqu'à 10 personnes par mois.
- Le bonus se dépense dans l'application : il ne peut pas être retiré vers un compte CCP ni envoyé à un autre utilisateur.
- Un parrainage frauduleux, par exemple avec plusieurs comptes à la même personne, annule les bonus et peut entraîner la suspension des comptes.
