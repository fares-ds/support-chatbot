# Cartes cadeaux et crédits de jeux

Achetez des cartes cadeaux et des crédits de jeux avec votre portefeuille, au prix affiché en dinars.

## Produits disponibles

- Cartes Google Play
- Cartes PlayStation Store
- Cartes Steam
- Diamants Free Fire
- UC pour PUBG Mobile

Les cartes Google Play, PlayStation Store et Steam sont vendues pour un pays précis, indiqué sur chaque carte : France, États-Unis ou Émirats arabes unis. Une carte ne fonctionne qu'avec un compte du même pays. Vérifiez le pays de votre compte avant d'acheter.

## Recevoir votre code

Le code de la carte s'affiche dans l'application dès que le paiement est accepté. Si vous avez enregistré une adresse e-mail, nous vous l'envoyons aussi par e-mail. Vous retrouvez tous vos codes dans Historique, puis Mes codes, pendant 12 mois.

## Diamants Free Fire et UC PUBG Mobile

Ces crédits sont envoyés directement sur votre compte de jeu : saisissez l'identifiant de joueur (ID) affiché dans le profil du jeu. Ils arrivent en moins de 15 minutes.

Des crédits envoyés sur un mauvais identifiant ne peuvent pas être récupérés. Vérifiez le pseudo que l'application affiche avant de confirmer.

## Un code ne fonctionne pas

Signalez-le dans les 7 jours suivant l'achat : ouvrez Historique, puis Mes codes, choisissez le code et touchez Signaler un problème. Joignez une capture d'écran du message d'erreur.

Nous vérifions le code auprès du fournisseur sous 72 heures. Si le code est invalide, nous vous donnons un nouveau code ou nous remboursons votre portefeuille.

## Remboursement

Un code qui a été affiché ne peut pas être remboursé, sauf s'il est invalide. C'est aussi le cas d'une carte achetée pour le mauvais pays : un code affiché ne peut plus être revendu.
