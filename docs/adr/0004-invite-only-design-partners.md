# ADR-0004: V1 is invite-only for design partners

- Status: Accepted
- Date: 2026-10-05
- Deciders: Fares

## Context

The first PRD draft assumed self-serve workspace creation, and measured a 30-minute time from signup to the first AI answer.

## Decision

There is no public signup in V1. The vendor onboards each design partner directly.

## Consequences

- Self-serve signup and its abuse controls leave V1 scope.
- The 30-minute activation metric needs a new definition for assisted onboarding, or removal.

## Open

- If each business runs its own copy, onboarding means installing that copy. Who performs and maintains the install is undecided.

## Update, 2026-10-05 (grilling round 3)

The vendor installs each copy; the business maintains it ([ADR-0009](0009-vendor-installs-business-operates.md)).
